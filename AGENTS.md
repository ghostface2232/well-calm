# well-calm

A wellness-companion app — a mobile-frame prototype built from a Figma design.
Three screens (State, Social, Ambient) plus a Calm detail view, rendered as a
centred 402px-wide column on a black background.

## Tech stack

- **Next.js 16** (App Router, Turbopack) + **React 19** — see the warning above
- **TypeScript 5** (strict)
- **Tailwind CSS v4** — `@import "tailwindcss"` in `app/globals.css`, no JS config
- **@squircle-js/react** — iOS-style squircle corners
- **SF Pro Rounded** — self-hosted via `next/font/local`

## Structure

```
app/
  layout.tsx        root layout — font, <body>
  globals.css       theme tokens + all mesh-gradient & view-transition CSS
  page.tsx          /         State home — greeting + metric cards
  social/page.tsx   /social   friends + Relay
  ambient/page.tsx  /ambient   control cards + sliders (client component)
  state/page.tsx    /state     Calm detail as a standalone route
  components/
    AppShell        shared frame — 402px column, header, tab nav
    MetricCard      a gradient card (wraps MeshGradient)
    MeshGradient    renders a GradientSpec — base + glow layers + rim + grain
    HomeCalmCard    Calm card → opens CalmModal via View Transitions
    CalmModal       full-screen modal wrapper
    StateDetail     Calm detail surface — shared by CalmModal and /state
  lib/gradient/     the mesh-gradient module — see its own README.md
```

## Key implementation

- **Mesh gradients.** Every card background is generated by `lib/gradient`
  (`cardGradient(preset, { value })`): deterministic (seeded PRNG), OKLCH
  colour. `<MeshGradient>` is a Server Component; the motion is pure CSS — soft
  lights drift, breathe and shift hue via `@property` custom properties
  animated in `globals.css`. Each card also has a soft inner-glow rim. Full
  details in `app/lib/gradient/README.md`.
- **View Transitions.** The Calm card expands into a full-screen modal by
  sharing `view-transition-name: calm-hero` across `startViewTransition()` —
  see `HomeCalmCard.tsx` and the `::view-transition-*` rules in `globals.css`.
- **Dark theme.** Black background, declared once on `<body>` in `globals.css`.
  Cards carry their own vivid gradients; chrome (tabs, ambient cards, sliders)
  uses translucent light-on-dark surfaces.
- **Squircles.** Rounded corners are squircles via `<Squircle>`, not
  `border-radius` — keep `cornerRadius={40} cornerSmoothing={0.7}` consistent.
- **Accessibility.** All motion respects `prefers-reduced-motion`.

## Dev workflow

- `npm run dev` — dev server. `npm run lint` — ESLint.
- **Do not run `next build` while the dev server is running.** Both write to
  `.next`, and the dev server then serves stale/broken CSS (grey background,
  missing rim). Verify with `tsc --noEmit` / `eslint` instead. To recover:
  delete `.next`, then restart the dev server.
